# AWS EC2 Apache Troubleshooting Lab

A hands-on AWS infrastructure troubleshooting project using Amazon EC2, Ubuntu Linux and Apache HTTP Server.

## Project Overview

This project demonstrates hands-on troubleshooting of common web server and infrastructure issues in an AWS EC2 environment.

It includes five practical scenarios covering Apache service management, network access, Linux file permissions, configuration validation and EC2 resource monitoring.

Each incident documents the investigation process, findings, troubleshooting commands and verification results.


## Environment

- Cloud Provider: AWS
- Service: Amazon EC2
- Operating System: Ubuntu 24.04 LTS
- Web Server: Apache HTTP Server
- Instance Type: t3.micro
- Region: Asia Pacific (Sydney)

## AI-Assisted Learning and Problem Solving

AI was used as a learning and troubleshooting assistant throughout this project to improve technical understanding and develop a more structured approach to problem-solving.

I used AI to:

- Understand Linux and AWS troubleshooting commands before executing them.
- Learn what commands do, why they are used and how to interpret their outputs.
- Clarify technical doubts and strengthen my understanding of unfamiliar concepts.
- Explore possible causes of infrastructure issues and understand different troubleshooting approaches.
- Improve investigation documentation, technical explanations and project presentation.
- Reinforce learning through practical exercises, command explanations and follow-up questions.

**My approach:** I used AI to support my learning, not simply to copy commands or solutions. I focused on understanding the reasoning behind each troubleshooting step, executing commands in my lab environment, observing the actual results and learning from the outcomes.

This helped me use AI as a practical learning partner to build stronger technical understanding, improve independent troubleshooting skills and learn more effectively.
