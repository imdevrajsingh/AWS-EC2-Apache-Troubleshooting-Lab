# AWS EC2 Apache Troubleshooting Lab

A hands-on AWS infrastructure troubleshooting project using Amazon EC2, Ubuntu Linux and Apache HTTP Server.

## Project Overview

This project demonstrates practical troubleshooting of common web-server and infrastructure issues in an AWS EC2 environment.

## Environment

- Cloud Provider: AWS
- Service: Amazon EC2
- Operating System: Ubuntu 24.04 LTS
- Web Server: Apache HTTP Server
- Instance Type: t3.micro
- Region: Asia Pacific (Sydney)

## Troubleshooting Scenarios

| Incident | Scenario | Focus |
|---|---|---|
| 01 | Apache Service Failure | Linux service management |
| 02 | HTTP Access Blocked | AWS Security Groups and networking |
| 03 | HTTP 403 Forbidden | Linux file permissions |
| 04 | Apache Configuration Error | Configuration validation |
| 05 | EC2 Resource Monitoring | CPU, memory and disk monitoring |

## Skills Demonstrated

- Linux command-line troubleshooting
- Apache service management
- HTTP connectivity investigation
- AWS Security Group troubleshooting
- Linux file permissions
- Apache configuration validation
- EC2 resource monitoring
- Log analysis and root-cause investigation
